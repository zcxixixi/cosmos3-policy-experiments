打开一层：只做两件事

36 层长得一模一样（权重不同）。每一层先“看别人”，再“自己想一想”。

2a · 一层的内部

先看别人（注意力），再自己消化（MLP）

“+” 的意思：每层只是在原有的数上加一点修改，不是重写。所以 36 层叠下来，动作是被一层层“微调”出来的，每层只贡献一小步。这与我们测到的现象一致：换指令后，第一层后动作向量只差 0.15%，叠到第 36 层才累积到 3.22%。

2b · 注意力在干什么

动作 token 在“问”：我该看谁？

一句话：每个动作 token 都会给每个别的 token 打一个“相关度”分数，分高的就多抄一点它的信息。文字 token 只是被看的一类，另外还有 250 个画面 token 和别的动作 token 同时在被看。

和我们的问题的联系：如果“牛奶”这个词的信息在这里只占很小的一份，而画面信息占大头，动作就会主要由画面（物体在哪）决定。这正是我们怀疑的情形之一，但目前还没有量过真实的分配比例。
