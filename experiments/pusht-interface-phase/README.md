# PushT 图像接口：分阶段分析

冻结已微调的二维图像 Diffusion Policy（U-Net / Transformer），沿用已完成的完整20步DDIM结果。78个观测、18个源示范组，示范进度20%、40%、60%、80%；终点单独移动或整体平移，各±32像素X/Y；配对种子3354、3355。

每次把一个图像条件入口换回移动前条件，其他入口正常读新图。分数是相对自然动作变化的有符号投影，不能当作成功率或相加成层贡献百分比。两种网络的各入口读取同一CNN输出，不是不同CNN层。

- 终点移动：U-Net入口4、Transformer入口0在四阶段均值都最大。
- Transformer入口0与各阶段事后选出的最强其他入口的配对95%区间，在两种变化中均为正。
- U-Net终点变化的80%阶段领先区间包含0；整体平移时入口4与早期入口差异在各阶段均不明确。
- 只保留最强入口新图信息仍不能复现完整动作变化，不能据此宣称单层足够或已修复任务。

原始采样审计见read-map-report.json；模型权重哈希不变，所有入口替换为旧图的实现与直接旧图推理最大动作误差为0。分阶段分析采用3000次源示范组配对bootstrap，保留各阶段、位移及种子配对；这是既有诊断数据的探索性分析，未做多重比较校正或独立盲测。

代码中的/home/current/work路径是原GPU主机，/dev/shm路径是分析时缓存位置；复现需相同模型、环境和原始actions.npz。采样目录：/home/current/work/pusht-interface-read-map。仓库中的JSON与代码不是完整权重/原始动作归档。
