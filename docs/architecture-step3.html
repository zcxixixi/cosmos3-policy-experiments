文字是怎么进到动作里的

这是我们诊断的核心。答案很短：文字有自己的一条通道，只通过注意力里的“被看”这一个口子，影响动作。

3a · 两条通道，单向连接

文字走一条，画面和动作走另一条

两点要记住：

① 文字通道是封闭的。它只在文字内部互相看，看不到任何画面或动作。所以不管牛奶在哪、桌上怎么摆，“抓牛奶”这句话在 36 层里的内部表示都是同一份。我们之前的检查也确认了这一点。

② 文字影响动作的起点，只有红色这一种。每层里，画面和动作 token 把文字 token 当作“被看的对象”之一（第 2 步里的注意力）。动作可以直接读文字，也可以先让“预测的未来画面”读文字、再去读那个未来画面（实验 13 查过这两条路）；但两条路的源头，都是红色箭头。

3b · 换一个词，哪些东西变了

换一个目标名，只有一小段文字表示变了

这样的话，语言对动作的全部影响就是：动作 token 在每层读到的、文字那 122 个 token 里的一小段不同。其余全部输入（画面、噪声、位置）完全一样。

所以我们看到 0.15% → 3.22%：这一点点不同，被 36 层一层层带进动作，累积出一个很小的差别。问题是，这个小差别有没有大到足以改变“抓哪个物体”。
