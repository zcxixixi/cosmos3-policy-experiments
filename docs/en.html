Cosmos3 Policy · Internal diagnosis

Why doesn't the robot pick the object we ask for?
Can we find the cause inside the network?

Milk, butter and a cream-cheese box sit on the table. We say “pick up the milk”, yet the arm may head for the cream cheese. We want to tell apart two cases: the model never uses the word “milk”, or it uses it but other information pulls the action away.

Current finding: language does reach the action computation, but which object gets picked mostly follows object position. Swapping internal information can push the arm to a different object, but we have not yet found a location that corrects it.
01 · How the model computes

From camera and instruction to robot action

Full architecture diagram → We study only the middle part. The network keeps a set of vectors representing the action about to be generated. Each layer reads the image and the text, updates these vectors, and at the end they are turned into arm commands.

02 · Does language get in?

Yes: changing one word makes the action vectors diverge layer by layer

So “language never enters the network” is ruled out. But note: a changed vector does not mean the right object is chosen; the arm may still go to the same thing, and the percentage is not a score of how much the model understood.

03 · Then what does it follow?

“Pick up the milk” in four layouts: it follows position

After the milk is moved away, the arm picks the cream cheese. When we then swap the cream cheese and the butter, it does not follow the cream cheese; it picks the butter sitting where the cream cheese used to be. The choice is driven more by that location than by the name in the instruction.

It is not deaf in general: in another scene, the same image with “bowl” picks the bowl and with “wine bottle” picks the bottle. The problem is that in some layouts, position overrides language.

05 · External confirmation

Reply from the Cosmos discussion: a common failure, not unique to this model

Weak language sensitivity appears to be a common failure mode among open-source VLA/WAM policies after task-specific SFT. We observed similar behavior in the LIBERO-finetuned checkpoints of Cosmos3, π0.5, and LingBot-VA. … This is consistent with the broader problem of policies relying on familiar visual context more strongly than language instructions.
