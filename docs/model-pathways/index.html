② / ③ 展开看：我们用的三个模型

箭头表示读取关系，不表示两条分支同时执行。
输入与理解动作／生成预测的未来画面

最关键的区别

π0.5：动作专家读取画面和指令信息，通常不显式生成未来视频。
Cosmos 3：未来画面与动作在生成分支内联合去噪，可以通过分支内注意力交换信息。
Long-WAM：动作专家读取视频专家的历史与未来表示；视频专家不反向读取动作。

图里的 L0 → L1 是什么？

每个方框代表一层 Transformer 的计算。竖线是隐状态继续传到下一层；横线是右侧通过注意力读取左侧信息。
K/V 可以理解为供右侧查询和读取的信息。右侧还会处理自己的隐状态，不是只复制左侧。
这是结构示意，不是逐算子执行图。π0.5 展示对应层的前缀 K/V 读取；Cosmos 3 展示共享多模态注意力中的 AR→生成分支读取；Long-WAM 展示非对称视频→动作读取，具体调用顺序取决于推理模式。Long-WAM 的文字条件为简洁省略。层数已核对本地实际运行配置：π0.5 LIBERO（gemma_2b＋gemma_300m）各18层；Cosmos3-Nano 原版与 LIBERO 微调版 num_hidden_layers=36；Long-WAM LIBERO-IDM 的 video_dit_config 和 action_dit_config 均为 num_layers=30。编号从0开始；这里不计视觉编码器、文本编码器、VAE内部层数，也不把去噪次数当层数。
