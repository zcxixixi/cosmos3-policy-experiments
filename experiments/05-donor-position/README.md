# 来源牛奶再移动6厘米，搬来的数组会有什么不同？

接收场景、指令、随机种子和替换方法不变。只把来源场景中的牛奶沿 X 移动6厘米，再取第30层数组。两个来源的正常运行此前都实际抓起过牛奶。

原位置来源让接收者抓黄油；移动后的来源让接收者抓奶酪盒。两次都没有抓接收场景的牛奶。

来源数组相对变化16.7%。接收者第一轮动作执行结束时，X 相对对照变化+9.1mm，而不是直接平移60mm。
