# 改目标要求在前期还是后期起作用？

我们不换整块hidden state，只在指定去噪阶段，让生成分支读取“拿黄油”的文本K/V，其余阶段读“拿牛奶”。比较前10次、中10次、后10次、全程换和原样运行。

两种布局、三个种子、五种阶段设置，共30组完整动作预测。检查确认文本状态在记录的各噪声阶段相同，也与物理布局无关，因此来源文本K/V能对应使用。

| 布局 | 前10次换语言 | 中10次 | 后10次 | 全程换 |
|---|---:|---:|---:|---:|
| 原始布局 | 0.004805 | 0.001553 | 0.003893 | 0.006920 |
| 牛奶移动15cm | 0.011474 | 0.001640 | 0.003499 | 0.012168 |

数字是最终归一化XYZ动作相对“全程拿牛奶”的RMSE，三个种子的平均值。它们不是成功率，前中后的作用也不应简单相加。

前期换指令通常影响更大，后期仍有影响，所以不能说语言只在最后才进来。全程换精确得到原生“拿黄油”的动作；原样运行精确得到原生“拿牛奶”的动作。

这些结果都是离线动作预测，没有新的闭环成功声明。它们帮助排除时间断路的简单解释，还没有让策略正确选择目标。
