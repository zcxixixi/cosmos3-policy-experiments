# Cosmos 式隐状态差分移植到 π

## 结果

同一中心场景，指令拿橙汁，种子 13000 / 13100 / 13200。最多执行 200 步，抓取判据沿用双指接触且抬高 2cm 持续 5 帧，不是入篮成功率。

| 方法 | 抓对橙汁 | 实际结果 |
|---|---|---|
| 原模型（单分支） | 0/3 | {'butter_1': 3} |
| 黄油参照 ×1（双分支、不放大） | 0/3 | {'butter_1': 3} |
| 黄油参照 ×1.3 | 1/3 | {'butter_1': 2, 'orange_juice_1': 1} |
| 黄油参照 ×1.5 | 2/3 | {'orange_juice_1': 2, 'butter_1': 1} |
| 黄油参照 ×2 | 3/3 | {'orange_juice_1': 3} |
| 黄油参照 ×3 | 3/3 | {'orange_juice_1': 3} |
| 空参照 ×1.3 | 0/3 | {'butter_1': 3} |

## 实现

π0.5 LIBERO 原权重。两分支共享图像、状态及每一步当前动作噪声 x_t，分别编码橙汁与参照指令。在动作专家 L16 输出处，目标状态替换为 h_ref + 1.3*(h_target-h_ref)；参照状态不改。只用目标分支速度更新动作，再把同一 x_t 送给下一次两分支去噪。共 10 步去噪，每次重规划执行前 5 个动作。批处理两分支，未加载或启用旧固定修正方向（旧服务器兼容字段仍在，repair 始终为 false）。

这是迁移 Cosmos 的差分操作；π 没有 Cosmos 的未来画面生成分支，因此作用范围是 π 的动作专家。固定 L16；先测倍率1.3，随后按用户要求扩大到1.5、2、3。全部沿用相同三个种子，没有扫层。

## 验证

所有配对初始图像和机器人状态逐元素一致。单分支与双分支存在浮点批大小差异，初始动作最大差约 0.00348，因此补跑了同批大小的倍率1对照。倍率1与“两句完全相同、倍率1.3”输出应逐元素相同，详见 sanity.json。每次请求断言 L16 干预钩子调用10次。

## 结论

初始倍率1.3只修好一个种子，空参照没有修好。追加后，倍率1.5为2/3，倍率2和3均为3/3。每档仅3个相同种子，不能视为新种子或泛化验证。
