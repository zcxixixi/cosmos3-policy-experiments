# 把会抓牛奶的内部数组搬过来，能救它吗？

来源是原始布局，实际能抓起牛奶的运行。接收者是牛奶、黄油互换后，原本会抓奶酪盒的运行。两边都说“拿牛奶”。

我们取来源的动作 token hidden state，分别在第12层或第30层替换接收者。第一轮预测的30次去噪都替换，后面7轮不再干预。输入不是完整示范视频或示范动作。

| 操作 | 接收者实际抓起 |
|---|---|
| 不替换 | 奶酪盒，约24.0cm |
| 换第12层 | 奶酪盒，约23.3cm |
| 换第30层 | 黄油，约28.9cm |

黄油现在位于来源场景中牛奶的原位置。内部数据影响了行为，但没让它去抓接收场景的当前牛奶。
