# 同长度名称对照与末层文字读取核验

日期：2026-10-05。对象：当前社区Cosmos3 Nano LIBERO权重、自定义推理程序与task7场景；无新增训练。

## 这轮想分清什么

此前把“cheese”写成“cream cheese”会改变抓取，但也多了一个token。这轮用实际合理的“milk box”和“cream cheese”，两条prompt均11个token，目标均两token，位置48／49相同。只换名称，不补padding，不改变其余排列。完整UND122、GEN266、joint388。

输入是实际恢复的12厘米和15厘米场景；两个场景各有自己的真实图片、状态和控制器。未来噪声195／198，动作与runtime195。每条8轮、128个实际动作，首轮使用冻结的内部条件；后7轮按recipient指令原生推理。

## 内部结论

[L35捕获后缀核验](matched-names-analysis/analysis.json)：两个名称各自的120份原生K/V（2位置×2噪声×30去噪）逐字节全相同。不同名称之间实际有非零差。被检验的是UND第48～121共74行，不是全网络。文字侧这段状态保持固定，符合其架构；接下来应检查读取者、其他输入或下游响应。不能声称语言脑区、目标概念解码、根因或“背动作”已经找到。

[真实NPZ](matched-names-analysis/arrays.npz)保留720个末层动作状态的BF16原始uint16位模式、真实逐head/逐动作RMS、实际接触／抬升与控制数字。uint16表示位模式，不能当整数活动。离线FP64注意力从真实Q/K计算，不是BF16 backend权重或因果重要性。

## 公开数据范围

[publication-manifest.json](publication-manifest.json)逐文件记实际SHA。公开全部24物理轨迹与192完整预测；全部producer非边界／dispatch文件；240份原生末层稀疏Q/K/V与动作注意力输出；4份15厘米原生首个去噪的完整37边界；封存分析NPZ。其它完整内部PT保留A6000，公开原捕获索引与SHA。真实输入目录链接未发布，也未构造不存在的合并metadata目录。

[代码](code/)使用原A6000绝对路径与已有冻结依赖；不是任意电脑的一键包。冻结producer SHA04469788、runner6b5ea13b、analyzera0ff5732；完整SHA在各complete/provenance文件。
